# Финансовая математика - Презентация

## Задание

Создать презентацию по финансовой математике (Вариант №1) с использованием Reveal.js и Markdown.

Презентация должна включать:
- Титульный слайд
- Определение финансовой математики
- Формулы наращения и дисконтирования по простым и сложным процентным ставкам
- Описание 3 практик начисления процентов
- 12 примеров задач с подробным решением
- Таблицу порядковых номеров дней в году
- Программу на JavaScript для расчёта кредита
- Исходный код программ
- Заключительный слайд

## Требования

- Презентация выполнена с помощью фреймворка Reveal.js
- Используется локальная версия фреймворка
- Каждый слайд вынесен в отдельный Markdown файл
- Тема оформления вынесена в отдельный CSS файл
- Установлен плагин menu для навигации
- Минимальное количество слайдов: 20
- Наличие навигации: стрелки, номер слайда
- На слайдах нет скроллов
- Минимальное количество изображений: 3

## Запуск

1. Откройте `index.html` через Live Server в VS Code
2. Или запустите локальный сервер: `npx serve`
3. Откройте браузер по указанному адресу

## Структура проекта

- `index.html` — главный файл презентации
- `css/theme.css` — файл темы оформления
- `table-generator.css` — файл темы для таблицы дней
- `calculator` — файл темы для расчета процентов(3 вида)
- `slides/` — папка с Markdown файлами слайдов
- `plugin/` — плагины Reveal.js (reveal, markdown, highlight, menu)
- `images/` — папка для изображений
- `README.md` — этот файл

## Навигация

- **Стрелки влево/вправо** — переключение слайдов
- **Кнопка меню (гамбургер)** — быстрый переход к слайду
- **Номер слайда** отображается внизу экрана
