# Презентация по финансовой математике

## Задание
1. Презентация должна быть выполнена с помощью Markdown, где это возможно. Каждый слайд на Markdown вынесен в отдельный файл.
2. Презентация выполнена с помощью фреймворка Reveal.JS (локальная версия в папке `plugin/`).
3. Тема (оформление) вынесена в отдельный CSS файл `theme.css`.
4. Минимальное количество слайдов: 20 (в презентации 41 слайд).
5. Перед каждым разделом используется слайд-разделитель с заголовком («ТЕОРИЯ», «ПРИМЕРЫ», «ПРОГРАММЫ», «ЗАКЛЮЧЕНИЕ»).
6. Оформление читаемое (используется тема Tokyo Night с контрастным текстом `#c0caf5` на фоне `#1a1b26`).
7. Присутствуют титульный и заключительный слайды.
8. Наличие меню для быстрого перехода (плагин reveal.js-menu). Все слайды имеют наименование в меню.
9. Наличие навигации: стрелки, номер слайда (включено в `Reveal.initialize`).
10. На слайде нет скроллов (настроено через CSS: `overflow: hidden`).
11. Изображения — присутствуют 
12. Используется локальная версия фреймворка Reveal.js

## Структура проекта
- `index.html` — основной файл презентации.
- `css/` — стили:
  - `theme.css` — основная тема оформления (Tokyo Night Deep).
  - `calculator.css` — стили для отдельного калькулятора.
  - `table-generator.css` — стили для генератора таблицы.
- `slides/` — Markdown-файлы слайдов и примеров.
- `plugin/` — локальные файлы Reveal.js и плагинов (menu, highlight, markdown).
- `day-table-generator.html` — генератор таблицы порядковых номеров дней в году.
- `credit-calculator.html` — калькулятор расчёта кредита.
- `README.md` — описание проекта.

## Как запустить
Откройте файл `index.html` в браузере через локальный веб-сервер (например, расширение Live Server в VS Code или команду `python -m http.server`), так как презентация загружает Markdown-файлы через `fetch`.

## Навигация
- Стрелки вправо/влево — перелистывание слайдов.
- Клавиша `M` или кнопка меню — открытие меню для быстрого перехода.
- Кнопки навигации и номер слайда отображаются в правом нижнем углу.
- `F` — полноэкранный режим, `S` — режим докладчика.
